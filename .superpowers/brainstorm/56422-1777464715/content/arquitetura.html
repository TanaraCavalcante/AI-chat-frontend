Por que o api.py é necessário?

❌ Sem api.py — não funciona

Laravel é PHP. PHP não consegue importar nem executar funções Python diretamente. Não existe chamada $rag->buscarContexto() a partir do PHP.

✅ Com api.py — funciona

O api.py transforma o código Python em endpoints HTTP. O Laravel faz Http::post('localhost:5000/api/chat') — igual a chamar qualquer API externa. Linguagens diferentes, comunicam por HTTP.

O que o api.py faz em concreto

POST /api/upload
  1. Recebe ficheiro do Laravel
  2. Guarda em /tmp
  3. Chama carregar_documento()
  4. Chama criar_vector_store()
  5. Guarda store em memória + devolve session_id
POST /api/chat
  1. Recebe session_id + pergunta
  2. Recupera o vector store da sessão
  3. Chama buscar_contexto()
  4. Monta prompt com contexto
  5. Chama Groq → devolve resposta
Resumo: O rag.py que já existe não é alterado. O api.py é só uma "embalagem HTTP" à volta dele — expõe as mesmas funções como endpoints REST que o Laravel consegue chamar.
